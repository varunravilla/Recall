# P2: Alpha (MVP)

## Core user journey

Maya logs into Recall, grants Photos access (web MVP: explicit permission; scanning is simulated), and uses **Add** to paste a concert caption as if a screenshot were detected. Recall proposes **Buy tickets** with a reminder about one minute ahead. She confirms; the item is **pending** in **Saved**. The inbox polls sweep every few seconds; when due, she opens the item and completes it.
