# Recall visual design study

The [two-slide P3 deck](Recall-P3-visual-study.pptx) studies typography and color.
Each slide collages two external visual references with a current Recall beta
screenshot. Margin annotations explain the specific choices used in the interface
and why they fit Recall. The PowerPoint text remains editable.

1. [Typography](slide-1.png): photographed Yellowstone signage, Apple's Newsroom
   page, and Recall's Add photos screen. The annotations explain how serif identity
   gives the collection character, how size and weight establish the first step,
   and why repeated controls use familiar system text.
2. [Color](slide-2.png): the Starbucks website, Yosemite's Tunnel View photograph,
   and Recall's Saved screen. The annotations connect these references to neutral
   surfaces for varied screenshots, a consistent primary action color, and a
   separate keyboard focus cue. Each explanation identifies an actual UI choice
   and its intended benefit for Recall's users.

Screenshots show the local beta on October 19, 2026. Font sizes and color values
come from `frontend/src/style.css`. This is the visual design study, separate
from the narrated application demo required by P3.

References are used for classroom design analysis, not as product backgrounds.
The images retain their original creators' rights. Source pages:
